# 東海岸帆船航行模擬

在瀏覽器裡開帆船的 3D 模擬器。場景是臺灣東海岸的臺東、綠島與蘭嶼，靈感來自博物館「臺灣玉的海上貿易」互動展品。
不需要安裝，手機（包含 iPhone）和電腦的瀏覽器都能玩。

## 特色

- **兩種船**：南島語族傳統邊架艇（蟹爪帆），以及參考 SailGP F50 的水翼雙體船（可以「飛」）
- **六個任務**：帆船教室、迎風繞標賽、環繞綠島、臺灣玉之路、橫風衝刺、自由航行
- **四種海況**：平穩、和風、大浪、暴風雨（風速與浪高大致對應蒲福風級 3、4、5、7 級）
- **物理**：視風、帆的升阻力、橫傾與扶正力矩、側滑、翻船；水翼升力、自動飛控、水翼破水與落水
- **海面**：Gerstner 波浪、細波紋法線貼圖、碎浪白沫、會殘留與漂移的航跡泡沫、陣風風紋、雲影與雲的倒影
- **地形**：海岸山脈、花東縱谷、中央山脈、綠島與蘭嶼，烘焙的山體陰影與大氣透視

## 操作

| 動作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 轉向 | A / D 或 ← → | 左下角 ◀ ▶ |
| 帆索收放 | W / S 或 ↑ ↓ | 右下角滑桿 |
| 水翼飛行高度 | Q / E | 帆索面板的 ▼ ▲ |
| 切換視角 | V | 「視角」按鈕 |
| 自動調帆 | T | 「自動調帆」按鈕 |
| 選單／暫停 | P 或 Esc | 右上角 ☰ |

拖曳畫面可以轉動視角，滾輪或雙指可以縮放。

## 檔案結構

```
index.html          ← 組好的成品，GitHub Pages 直接用這個
build.js            ← 把 src/ 組成 index.html（Node.js）
package.json        ← npm 指令：build、polar
src/template.html   ← 頁面結構與樣式（CSS）
src/physics.js      ← 物理：海浪、風、地形、兩種船的運動方程式（不依賴 three.js，Node.js 也能跑）
src/main.js         ← 3D 場景、著色器、操作介面、任務
tools/polar.js      ← 在 Node.js 裡跑物理，印出各風角的船速，改參數後用來檢查
```

修改 `src/` 裡的檔案後，執行一次（需要 Node.js 16 以上，不需要安裝任何套件）：

```bash
npm run build
# 或
node build.js
```

就會重新產生 `index.html`。檢查物理參數可以用 `npm run polar`（邊架艇）或 `npm run polar:foiler`（水翼船）。

## 本機執行

直接用瀏覽器打開 `index.html` 即可。three.js 從 cdnjs 載入，所以需要網路連線。

## 物理模型與參考資料

模型是為了即時互動而簡化的工程近似，不是研究等級的船舶模擬。參數對照過以下資料：

- 雙體航海獨木舟 Hōkūleʻa 的經驗法則：橫風船速約為風速的 1/3
- Irwin 等人（2023）對古代玻里尼西亞航海船的速度預測：最佳速度出現在真風角 90–120°，逆風約只能到 75°
- Marchaj 的風洞試驗：蟹爪帆橫風時的驅動力係數約 1.7
- 英國氣象局蒲福風級表：各風級的典型浪高
- SailGP F50 的公開數據：約 15 節起飛、最高船速約為風速的 3 倍

已知的主要簡化：波浪沒有依水深變形；風不受地形影響；船體的起伏搖擺用彈簧阻尼跟隨浪面，而不是積分排水體積；水翼船的強風極速偏保守。
